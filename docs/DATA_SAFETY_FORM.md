# GOOGLE PLAY CONSOLE DATA SAFETY FORM DECLARATION

## Data Collection & Sharing Summary

| Data Category | Data Type | Collected | Shared | Purpose | Encryption |
|---|---|---|---|---|---|
| Location | Precise Location | Yes | Optional (SOS/Squad) | App functionality, Navigation, SOS | Encrypted in transit |
| Personal Info | Name, Email | Yes | No | Account management | Encrypted in transit |
| Health & Fitness | Blood Group, Medical Info | Yes | SOS Only | Emergency response | Encrypted in transit & local secure storage |
| Financial Info | Fuel & Service Expenses | Yes | No | App functionality | Encrypted |
| App Info | Diagnostics, Crash Logs | Yes | No | Performance & analytics | Encrypted |
| Device IDs | Device Identifier | Yes | No | Security & Session Auth | Encrypted |

## Security Practices
- Data is encrypted in transit using SSL/TLS protocols.
- Data deletion request mechanism provided within user profile settings.
